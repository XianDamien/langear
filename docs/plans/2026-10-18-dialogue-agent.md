# LAN-21 情景对话首版

## 已确认需求（2026-10-18，替代旧版范围）

### 产品目标

本轮卡片练习结束后，用情景对话弹窗取代原总结报告体验，让学习者立即使用刚练过的表达。首版优先 Dialogue Agent，答疑 Agent 后置。

### 入口与范围

- 基于 staging 的新 Collection / Note / Card / Attempt / Review 模型，基线 `749a45f`。
- 本轮确实有已评分的 Attempt，且当前无可继续练的卡片时弹出场景窗口；首次进入空队列不触发，不代表整个 Deck 永久学完。
- 弹窗展示场景、双方角色、任务和 2–3 个目标表达，用户点击开始后 Agent 英文开场。
- 场景取自本轮实际练过的卡片、Attempt 内容快照与已有反馈；开始后场景、角色和任务保持稳定。

### Agent 与语音分工

- 直接采用 pi agent；独立 Node 服务负责场景准备与中文复盘。
- Qwen-Omni-Realtime 云端 API 使用 Manual 分轮模式，直接接收用户音频、返回文本与语音。
- 用户点击开始录音，再次点击结束并发送；展示双方文字记录并播放 Agent 回复。
- Agent 扮演场景人物，全程英语推进任务；不逐句打断纠错，听不懂时自然追问。
- 任务完成后自然收尾；最多 8 轮用户发言，用户可提前结束。
- 复盘简述任务完成情况、实际使用的表达及建议复练点，关联原卡片与 Attempt。仅文本证据不能推断发音结论。

### 数据与权限

- Python API 沿用新模型的会话认证与 CSRF，按认证用户的 Collection 隔离上下文、Dialogue Session、Turn 和 Review；创建时验证当前 Review queue 已耗尽，且提交的已评分 Attempt 集合与本轮完全一致。
- 模型不得决定 user_id / collection_id；pi 通过受控业务工具获取本次授权上下文，不直连 ORM/SQL。
- 持久化对话文字、固定场景与复盘；首版不写长期 memory。
- 保留新 Review / Processing / FSRS 链路；对话记录不作为 Attempt 或 FSRS 评分写入。

### 首版后置

开放式答疑、Markdown RAG、长期 memory、AI 卡片增删改、免按键连续对话、自动打断、Dashboard / Library 历史入口。

### 验收标准

- [ ] 正常完成一轮后弹出场景窗口；初始空队列、跳过/暂停、请求失败和撤回不误触发。
- [ ] 场景包含原卡片/Attempt 来源，角色与目标在会话内固定。
- [ ] Manual 音频输入、Agent 文字/语音回复和轮次管理可用。
- [ ] 任务完成、8 轮上限和用户提前结束均可进入中文复盘。
- [ ] 对话与复盘可查询，并隔离不同 Collection；外部 ID 无法越权读取。
- [ ] 网络中断可明确提示并恢复；不把部分回复当成完整发言或伪造反馈。
- [ ] 新 Review / Processing / FSRS 回归检查通过。

### 实现追踪

分支：`feat/lan-21-dialogue-agent`。生产发布不属于本次授权范围。

### 本轮验证记录

- staging 独立测试数据库：后端 `core_tests` 共 135 项通过，覆盖用户隔离、迁移、轮次入口、语音协议、断线恢复及 Review / FSRS 回归。
- 前端：101 项单元测试通过，类型检查通过；lint 无错误，保留仓库既有的 199 条 warning。
- pi 服务：2 项测试通过，类型检查通过；覆盖真实 pi 工具循环、多请求上下文隔离及 Qwen 的 system 角色与关闭思考模式配置。
- staging 真实模型冒烟通过：已评分卡片 → pi 场景准备 → Qwen 英语开场 → 英语合成音频输入及正确转写 → 英语文字/语音回应 → 提前结束 → pi 中文复盘与记录落库。该检查使用合成语音，未代替真人对话质量评测。
- 尚未进行浏览器页面与真人麦克风验收，以上自动检查不替代这两项体验验收。
