# LAN-21 练习后实时语音对话

## 已确认需求（2026-10-18，替代旧版 pi + 中文复盘方案）

本轮卡片练习结束后，用情景对话弹窗取代报告，让学习者立即使用刚练过的内容。主链路为：练习结束 → 后端装配上下文 → Qwen-Omni-Realtime 语音对话 → 保存完整对话记录。

### 入口与对话

- 基于 staging 的 Collection / Note / Card / Attempt / Review 模型，基线 `749a45f`。
- 本轮存在成功评分的 Attempt，且当前队列没有立即可练卡片时显示弹窗；初始空队列不触发。
- 后端校验当前 Review queue 与本轮完整的已评分 Attempt 集合，读取原卡片、内容快照、用户转写及已有反馈。
- 场景直接在后端装配。首版采用与英语朋友围绕刚练内容交流的固定角色，最多展示三个来自原卡快照的表达；只有一条内容时无需编造更多表达。
- 用户点击开始后，直接连接 Qwen-Omni-Realtime 云端 API。它以英语开场、推进对话，接收用户语音并返回文字与语音。
- Manual 分轮：点击录音，再次点击结束并发送。最多八轮用户发言；任务完成时自然结束，也允许用户主动结束。
- 结束后展示已保存的对话记录与完成按钮，不生成报告或中文复盘，不再请求其他模型。
- 原卡片/Attempt 可从目标表达查看。断线可恢复完整文字记录；部分响应不作为完整发言保存。

### 技术边界

- 去掉 pi 独立 Node 服务、场景规划请求、复盘请求和相关配置；实时对话只依赖 Qwen 语音凭据。
- 浏览器通过已认证的 Python WebSocket 网关连接；API Key 仅在后端。HTTP 写入验证 CSRF，WebSocket 验证 Origin。
- 按认证用户的 Collection 隔离 Deck、Attempt、Dialogue Session 和 Turn。模型不能指定其他用户的数据范围。
- 后端将经过裁剪的学习上下文直接注入 Qwen，固定角色与任务；Qwen 可调用受控的 `finish_scenario` 通知结束。
- 单轮最多 90 秒输入；PCM16 单声道输入 16kHz、输出 24kHz。原始对话音频不持久化。
- 不改变 Review / Processing / FSRS 评分链路；对话不写入 Attempt 或 FSRS 评分。
- 既有 `dialogue_reviews` 历史表保留数据兼容，但没有读写该表的业务接口，也不新增复盘数据。

### 验收

- [ ] 正常完成一轮后弹出对话窗口，初始空队列、撤回和失败不误触发。
- [ ] 无 pi 服务时仍可创建场景、完成语音对话并结束保存。
- [ ] Qwen 收到本轮授权学习上下文，场景角色与原卡引用保持稳定。
- [ ] Manual 音频输入、文字/语音输出、八轮上限、任务完成和主动结束可用。
- [ ] 结束后只展示记录，无复盘请求或额外模型等待。
- [ ] 多用户隔离、断线恢复和既有 Review / Processing / FSRS 回归通过。

### 实现与验证

分支：`feat/lan-21-dialogue-agent`。生产发布不属于本次范围。

- staging 独立测试数据库：后端完整回归 135 项通过；评审补充无中文翻译句子卡修正后，Dialogue 11 项专项测试通过。
- 前端 104 项测试和类型检查通过；lint 无错误，保留仓库已有的 199 条 warning。
- pi 容器停用时的真实云端冒烟通过：创建会话约 0.1 秒、英语语音输入正确转写、收到英语文字与语音、结束后记录落库；没有复盘字段，原复盘接口返回 404。使用合成英语音频。
- 浏览器页面与真人麦克风体验验收尚未进行；云端合成音频冒烟不能代替这两项检查。
