# 以练习记录(Attempt)作为练习事实

状态:已接受

当学习者翻牌(flip)一张卡片时,即创建一个练习记录(Attempt),此前翻牌前(pre-flip)的录音始终是临时性的。练习记录存储不可变的输入、笔记字段、渲染后的提示语(prompt)、答案以及媒体快照。ASR、AI 反馈与学习者的评分(Rating)是对同一练习记录的独立更新:评分是同步的并使 FSRS 推进;ASR 与 AI 异步执行,并且绝不会替学习者选择评分。ASR 或 AI 任务失败不会阻塞评分。

异步工作由 Celery 和 Redis 执行。每个独立任务都会在与练习记录相同的数据库事务中创建一行 PostgreSQL `task_outbox`,从而提供可靠的至少一次(at-least-once)投递。工作进程(Worker)必须按练习记录 ID 实现幂等。业务记录以练习记录数据为准,而非 Celery 结果数据。
