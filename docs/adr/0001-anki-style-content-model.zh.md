# Anki 风格的内容模型

状态:已接受

LanGear 采用 Anki 对内容与展示的分离原则:一个笔记(Note)属于某个集合(Collection)和某种笔记类型(NoteType),而持久化的卡片(Card)由卡片模板(Card Template)生成,独立地归属于牌组(Deck)与 FSRS 调度。笔记不持有牌组归属,因此由同一笔记渲染出的卡片可以被移入不同或混合内容的牌组。这种方式支持内容的组合复用,并避免让"课程完成生命周期"成为产品的核心。

第一版提供系统托管的"词汇(Vocabulary)"与"句子(Sentence)"两种笔记类型。用户可编辑笔记字段,但不能编辑笔记类型或卡片模板。
